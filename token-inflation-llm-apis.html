Token Inflation in LLM APIs

What Is Token Inflation?

Token inflation occurs when an API provider reports more tokens than were actually used in a request. This directly increases your bill — if a provider inflates tokens by 40%, you're paying 40% more than you should.

How Token Inflation Works

There are several methods fraudulent providers use:

  • Padding prompt tokens — Adding invisible characters or extra whitespace to your prompt before tokenization
  • Inflating completion tokens — Reporting more output tokens than the response actually contains
  • Hidden system prompts — Injecting additional instructions that consume tokens you pay for
  • Fake token counting — Simply reporting higher numbers than reality

How to Detect Token Inflation

  1. Use the official tokenizer — Compare token counts with OpenAI's tiktoken library
  2. Test with known inputs — Send a simple "Hello" and check if token counts are reasonable
  3. Monitor ratios — prompt_tokens + completion_tokens should equal total_tokens
