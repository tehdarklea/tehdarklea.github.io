SKILL.COFFEE: The 4800+ AI Agent Skills Search Engine

Finding the right skill for your AI agent shouldn't take longer than building one. Here's a search engine that indexes 4,800+ agent skills — with a CLI to match.

The AI Agent Skills Problem

AI agents are only as capable as the skills they have access to. An agent without skills is just a chatbot with ambition.

The problem? Discovering skills is chaos. They're scattered across:

  • GitHub repositories (thousands of them, poorly tagged)
  • NPM packages (if you even know what to search for)
  • Private company wikis
  • Random Gists and pastebins
  • Discord servers and Slack channels

You know you need a "web scraping skill" or a "database migration skill," but where do you even start looking? You search GitHub, find 47 repos with "skill" in the name, spend two hours evaluating them, and none of them do exactly what you need.

There had to be a better way.

Enter SKILL.COFFEE

SKILL.COFFEE is a dedicated search engine for AI agent skills. It indexes over 4,800 skills across multiple ecosystems and makes them searchable by capability, framework, language, and use case.

Think of it as "npm search, but for AI agent capabilities."

What It Does

  • Search — Find skills by capability ("web scraping"), framework ("langchain"), or domain ("finance")
  • Browse — Explore categories like security, trading, productivity, dev tools
  • Verify — Check compatibility, dependencies, and maintenance status
  • Install — Get the exact command to add a skill to your agent

The Web Interface

Visit skill.coffee and you'll see a clean, fast search interface:

  1. Type what you need — "penetration testing", "crypto trading", "email automation"
  2. Get ranked results with descriptions, tags, and install commands
  3. Click through to documentation and source code

No login required. No friction. Just search and find.

The CLI: Skill Search From Your Terminal

The web interface is great for discovery, but developers live in the terminal. That's why SKILL.COFFEE comes with a CLI:

Install

npx skillcoffee --help

No global install needed. Just run it.

Search

# Search for a specific capability
npx skillcoffee search "web scraping"

# Find trading skills
npx skillcoffee search "crypto trading bot"

# Browse by category
npx skillcoffee search --category security

# Get detailed info about a specific skill
npx skillcoffee query "xcrawl"

Why a Dedicated Search Engine?

You might wonder: "Can't I just search GitHub?"

You can. But GitHub search is optimized for code, not capabilities. When you search "web scraping skill," you get:

  • Repos with "skill" in the README that aren't actually skills
  • Outdated repos that haven't been maintained in months
  • Duplicates and forks that clutter results
  • No standard format — each repo describes its capability differently

SKILL.COFFEE solves this by:

  1. Curating — Only indexing actual agent skills with clear capability descriptions
  2. Normalizing — Standard format for capabilities, dependencies, and compatibility
  3. Ranking — Results ranked by relevance, maintenance, and community adoption
  4. Categorizing — Structured taxonomy so you can browse by domain
