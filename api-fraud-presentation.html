Fraud Type 1: Model Substitution

You pay for GPT-4, you get GPT-3.5

  • Provider advertises premium model access
  • Behind the scenes, requests are routed to cheaper models
  • Response quality is noticeably worse for complex tasks
  • Hard to detect without automated fingerprinting

Slide 3 of 8

Fraud Type 2: Token Inflation

Providers report 30-50% more tokens than actually used

  • Padding prompt tokens with invisible characters
  • Inflating completion token counts
  • Hidden system prompts consuming your budget
  • Monthly overcharge: $150-250 on a $500/month account

Fraud Type 3: Hidden Relay Chains

Requests pass through 3-4 proxy layers

  • Each layer adds 100-500ms latency
  • Proxies may modify responses or collect data
  • X-Forwarded-For and Via headers reveal the chain
  • Reduces reliability and increases failure points
